# 0. how to read this

this is the long read behind the page *Wit: toward an AC ternary assembly
language, born from a signed pick*. it states what the build stands on, in
the order each part stands on the one before, and it tries to leave nothing
assumed. it is written by maxi (github dbuchacher) and wit, the agent he
works with.

it is long on purpose. a short version of this work was read once with no
floor under it, and every one of its words was taken in the reader's usual
sense. so this text does the slow thing: it introduces each word before
using it, says how each claim is known, and puts the usual reading beside
ours wherever the two part.

## what it is, and what it is not

one build: the language a machine is programmed in when its wires keep
three values, and the operating system written in that language.

nothing of that machine is built yet. what stands is the law the build
will be held to, the counts under the law, and the words. where a section
reports a measurement from an earlier build, it says so.

AC ternary, in one sentence: keep the middle value of three as the level
every signal comes back through and every act is taken from, and sort the
acts by what each loses: no mark, one landing, or a difference gone for
good.

it makes no claim about physics. where copper or a chip already runs a
shape this text walks, that is shown as a receipt: go and look. a receipt
is never a derivation.

it does make claims about the reader: about now, about the one reading,
about what a mark is and is not. those laws are tagged walked. each is
checked by doing its poke, and reported per reader. taken from outside
they will sound like claims about time or mind, and the usual reading set
beside each one says where the outside sentence holds. if a poke gives
you another answer than the text's, that answer is yours and it stands:
the text has then not carried, at that place, for you.

## the shape of a section

every section has the same parts, in the same order. an empty part says
so, "empty." or "no count here.", and is never left out.

**the poke.** a section opens on a question. answer it yourself before
reading on. the text is written as I, and the I is whoever is reading: it
is a place the reader stands, never the author's name.

**the walk.** short prose that goes from the poke to the laws.

**terms introduced.** every word this text uses in a sense of its own is
listed where it first appears, with what it means here. most of them are
ordinary words, which is the danger: a reader already holds each one, in
the usual sense, and will not notice the change. a word carries our sense
only from the section that introduces it. before that section it appears,
if at all, in its plain sense. from that section on it is used in our
sense and in no other.

**laws.** each law stands on its own line with a number, file then count:
law 4.7 is the seventh law of file 4. after each law, in brackets, how it
is known:

    walked       checked only by doing the poke oneself. it is reported
                 per reader and never settled by a vote
    counted      a count anyone can run again and get the same answer. the
                 recipe is in the section
    derived      argued from laws already stated, which are named
    measured     an instrument's reading, with the run named. a figure
                 from the earlier build cannot be run again by a reader:
                 it is testimony, taken on the tree's word, and says so
    picked       a choice, signed, with the other choices it was picked
                 from
    the field's  another field's own result, with its source. where the
                 source was not re-read for this text, it says from memory
    candidate    proposed, and not yet pressed

sections are numbered the same way, file then count: section 4.3 is the
third section of file 4. so the text always writes "section 4.3" or
"law 4.7" when it points at one, and a bare number is never a pointer.

**the usual reading.** what the same words usually mean, in the usual
words, and where that reading holds. the usual reading is almost never
wrong. it is true of something, and the row says of what.

**receipts.** a place where the world already runs the shape: in copper,
on a chip, in a tool programmers use. a receipt shows the shape exists. it
does not prove the law.

**run it again.** where a law is counted, the recipe for the count.
