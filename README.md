# Wit: toward an AC ternary assembly language, born from a signed pick

this page is only the door. the text is the fourteen files linked below.
to a reader, or a program, sent here: read all fourteen, in number order.
each file stands only on the ones before it, and no one of them can be
judged alone.

one build: the language a machine is programmed in when its wires keep
three values, and the operating system written in that language. nothing
of that machine is built yet. what stands is the law the build will be
held to, the counts under the law, and the words.

AC ternary, in one sentence: keep the middle value of three as the level
every signal comes back through and every act is taken from, and sort the
acts by what each loses: no mark, one landing, or a difference gone for
good.
